# Connected park details

Rounded cartoon base-only PNGs for shared park scenes. `terrain-hedge` is an opaque,
seamless 512px leaf material used along continuous hedge contours. The other eight
256px transparent props provide flower beds, fruit trees, reeds, rocks, lily pads,
bridges and a planter. These are scene ingredients, not complete square scene tiles.

Mapped by `props.ts`; placements, planting themes, shared hedge silhouettes and
cosmetic paths live in `town-terrain.ts` / `town-terrain-art.ts`.

Generated from the approved cartoon park reference, with a separate transparency
cleanup pass. All earlier asset folders remain available for rollback. Fixed colors
need no tint layers.
