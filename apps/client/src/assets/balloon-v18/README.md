# Balloon travel sprite

Painted hot-air balloon for the live travel animation, separate from the balloonport tile.
Aligned 512×768 base/tint PNGs: wicker, ropes and cream panels stay fixed; grey canopy panels take the rider’s color. The transparent suspension gap leaves the rider visible.

Generated source is retained outside the repository. The original canvas drawing in `travel-art.ts` remains the loading fallback.
