# Cartoon town scene artwork (preserved)

Nine complete 320 × 320 cartoon scene PNGs: fountain courtyard, grove, pond, formal
garden, orchard, picnic garden, flower meadow, gazebo courtyard and hedge garden.
The scenes use rounded colorful forms and soft alpha edges, without sticker rims.

This artwork is preserved for reuse/reference. The game now joins material cells
into continuous, irregular locations using `terrain-v8/`, rather than drawing these
as self-contained square scenes. No earlier PNG assets were removed.
