# Random suit tile

`random-suit-base.png` is a 512×512 transparent, fixed-color board icon: an upright ivory card with a gold rim, navy spade, coral heart, gold diamond, green club and gold shuffle arrows.

No tint layer: these colors identify suits and must stay fixed. The explicit base mapping prevents automatic recoloring. Used in the board, builder palette and UI Lab’s Random suit tile demo. The earlier card and suit sprites remain unchanged.
