# Gain / Lose money tiles

Fixed-color, transparent 512px PNGs for the `gain` and `loss` special tiles. A blue/red circular
backing and a gold plus/minus coin distinguish the effects even without color. Matches the
painted toy-town board art. `props.ts` registers both as explicit base-only sprites so blue is
never recolored. No tint mask needed. Built assets use the existing lossless-WebP pipeline.

Generated source: `exec-450062c6-fbec-4abc-a883-aa69d0422f58.png`. Icons were mechanically
separated, trimmed and resized with equal transparent margins. All earlier artwork is preserved.
