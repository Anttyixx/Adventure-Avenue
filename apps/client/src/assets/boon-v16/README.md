# Boon burst with a smaller plain coin

Fixed-color 256px base PNG. The central gold coin is 30% smaller in diameter than
the v15 up-arrow coin, and its face is plain. The green burst keeps its overall
size, cream trim and decorative rays. No tint layer is needed.

Generated as an edit of the v15 sprite, then normalized to the same transparent
frame. `BOON_SET = burst` selects this version; the v15 coin and original tile art
are preserved. `BOON_SET = previous` restores the original standalone coin.
