# Code map

Where everything lives. Files are listed with what they do and their key exports or functions;
the "Where is ..." index at the bottom maps game features to code. Search for the function names
given here rather than line numbers (line numbers go stale). How the pieces work together is in
`docs/architecture.md`; the game's rules are in `docs/spec.md`.

Keep this map current: when you add, move or rename a file or a major function, update it here.

`park-scenes.ts` defines reusable activity/planting modules, composes arbitrary connected footprints
and plans free-space groups on the actual board grid (`composePark`, `parkScenes`).
`park-scenes-art.ts` cancels shared square/hex edges and caches assemblies with continuous
hedges, ground, water and paths (`parkBoundary`, `paintParkScene`, `paintParkScenes`).
The puzzle scene implementation is preserved for rollback. `town-terrain.ts` defines connected park/water/courtyard cells, traces region contours, and plans
park amenities/courtyard anchors for the older mode. Default `townBackgroundFeatures` places
foliage and sparse benches near the board. `town-terrain-art.ts` paints continuous material surfaces with
soft masks and camera-scaled world chunks using `assets/terrain-v12/`; decoration PNGs draw
at native resolution with cached placement plans. Earlier textures remain in `terrain-v8/`.
`meadow.ts` builds cached, coordinate-seeded grass chunks with smooth patch blending.
`travel-art.ts` draws the rides' effects (`drawBeam`, `drawVortex`, `drawPuff`, `drawStar`,
`drawTaxi`, `drawBalloon`) for `BoardView.travel`; `props.ts` `drawPropCentered` centers a symbol.
`foliage.ts` draws the light river and foliage on the solid ground (`paintFoliage`).
`ground.ts` bakes the textured ground (meadow + terrain) into cached chunks for live views
(`paintGround`, `warmGround`); unused while `GROUND_SET` is `solid`.
`chunk-budget.ts` holds the shared chunk rules for both: half, 1x or 2x resolution (`chunkLevel`), at most one
new chunk built per live frame with the other resolution standing in (`chunkBudget`), and trimming that
never drops chunks drawn this frame (`trimChunks`).
`scenery.ts` owns cosmetic coordinate randomness and small scenery placement, inside the board
(`sceneryForBoard`) and beyond it (`parkSceneryBeyondBoard` for grouped park scenery,
`sceneryBeyondBoard` for the preserved earlier scatter). It never changes engine state.
`park-geometry.ts` defines the cosmetic stream and planting clearance outside the playable map.
`park.ts` paints its textured water, organic banks and contact shadows beneath scenery.

`portal-links.ts` resolves exact reciprocal endpoints and permitted flow. `portal-link-art.ts`
draws one-way and two-way arcs for the builder/game. `portal-travel.ts` supplies the pure pull-in,
vanish and launch-out poses used by `BoardView.portalStep`.

## Browser storage keys

All in `localStorage`, prefixed `adventure-avenue-`: `save-v1` (the saved game), `options` (last
setup), `audio`, `fast` (Fast CPU), `names`, `online-name`, `net-token` (this device's id
online), `guest`, `guest-in-game` (rejoin info), `boards` (custom boards), `stocks-lab`,
`stocks-lab-live`, `seen-update`, `update-tried`.

`apps/client/src/ui/status-messages.ts`: action-phase transitions, bounded in-phase event queue, short reading slots,
debounced fallback and immediate decision interruption; tested with fake timers.

Arcade games on screen: `apps/client/src/ui/arcade.ts` (`ArcadeStage`: the board in the middle plus action-bar prompts for all five games). Engine scoring and games live in `packages/engine/src/arcade.ts`.

`packages/engine/src/boards/portal-maps.ts` defines Crossgate Gardens (square courtyards) , Prism Junction (four hex petals) and Return Ridge (square dead-end branches). `fromMap` accepts explicit reciprocal portal coordinate pairs, marked as portal tiles and turned into portal links by `convertPortalTiles`; `portal-maps.test.ts` checks district relief spacing, real movement reachability, portal links surviving export, and complete matches.

`assets/tiles-v2/README.md` describes the layered board PNGs and classic rollback. `props.ts` exports `ART_SET`, `ART_SOURCES` and `drawStamp`; `tile-assets.test.ts` checks coverage and matching base/mask dimensions.

`assets/properties-v3/README.md`: new nineteen-building set, base/tint contract and property-only rollback (`PROPERTY_SET`).
